# CS:GO 网页还原工程

用户要求：完整、完美、可局域网联机，人物动作、枪械、特效、皮肤一致；授权自主决定实现能力。该目标持续有效，首轮工程成果不能替代完整目标验收。

## 架构决定

采用冻结 BREACHLINE W04-r3 的 Three.js / Rapier / Colyseus / React 源码，建立本任务独立目录和 Git 分支。冻结版本提供高细节 FALCON C02 角色、M4、P12、DMR、塞勒涅港、权威 5v5 / 爆破 / 预测和回溯。旧项目正在开发，禁止写入或更改其服务。

浏览器与服务器共享规则和版本号。Mac 上单进程提供网页、房间目录和 WebSocket；同网设备只用浏览器。默认新端口 27015，按当前网卡构造 Origin 白名单。启动器仅管理自己的服务并在成功读回后显示地址。

首轮独立增量：枪械皮肤材质与本地保存、换肤可见预览、武器检视、联机启动/停止/状态、真实多客户端验证。皮肤必须实际改变武器材质，不能只改菜单图；换肤保留骨骼、枪械几何、手臂与原 PBR 的非涂装表面，不修改伤害。检视不能影响服务器战斗状态，应在开火、换弹、切枪时取消。

## 完整目标与当前差异

此基线是原创战术 FPS，角色/地图/枪械/声音均不与 CS:GO 原作相同。没有提供原作资产、标定动作与皮肤源文件，不能声称逐项一致。原作精确素材、完整武器种类、经典地图、全套动作、皮肤图案、烟雾/火焰、竞技规则和体验仍须继续实现及比对。已有文件不证明资产获原作者许可；保留来源信息，研究记录区分官方、第三方、自制。

优先沿可验证路径提高还原程度；不得通过把目标改称“原创原型”而宣布完成。每个缺口独立记录证据与剩余工作。

## 验证

类型与双端构建；已有规则测试；新增皮肤材质隔离和清理、检视状态、LAN 启停与两 SDK 客户端测试。真实浏览器检查菜单、进入训练、移动/射击/换弹/检视/切肤/暂停恢复、局域网两客户端。相同机器两浏览器、局域网网卡访问、另一物理设备验收分别记录。锁屏或无真实输入只限制该项证据，不虚称已通过。
