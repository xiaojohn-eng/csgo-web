# 2026-09-14 连续操作复审

本轮在工作树并行开发后进行反向验证：先复现错误，再修复并重跑相关路径。原 Alpha 审查和完整目标仍有效，本记录不能替代两台物理设备的完整对局验收。

## 已复现并修复

| 问题 | 当前验证 |
| --- | --- |
| 服务器重复使用最后一条输入，导致重复丢枪 ID 异常 | 命令序号一次性消费；真实 Source SDK 连续 tick 验证 |
| 按住 E 反复交换地面手枪 | 只在新的按下沿拾取；持续种拆包仍按持续按键处理 |
| 最近的不可拾取步枪挡住可拾取手枪 | 先筛选槽位与空间可达性，再选最近物品 |
| 跨楼层、隔墙拾枪 | 高度及原地图视线约束回归 |
| 拾取手枪后切回步枪，弹药错误恢复 | 切换前统一保存所持枪械状态 |
| 持刀购买手枪会清空步枪弹药 | 统一收枪路径，刀不覆盖主武器弹药 |
| 拾取 USP-S 会重置消音器 | 恢复附件状态和对应射击模式 |
| 丢弃手枪后未选剩余主武器 | 自动选择仍持有的主武器并保留弹药 |
| 丢掉全部枪后幸存进入下一回合报错 | 允许刀具作为唯一库存 |
| 刷新页面主动离房导致恢复令牌失效 | 页面清理使用可恢复断线；真实 SDK 同 roomId/sessionId 验证 |
| 刀具隔墙、跨层、超距离命中和右键单独失效 | 原地图遮挡、3D 距离、最近目标与单独右键回归 |
| 持刀缺少人物命中盒 | 与当前显示身体一致的原始 AK 人物骨骼/OBB 绑定；加载真实角色数据验证 |
| 子弹忽略第二面墙，或错用重叠碰撞体出口 | 入射碰撞体限定出口；最多四层逐层衰减、最近目标选择；AWP 与训练同路径 |
