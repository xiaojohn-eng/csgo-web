## 运行边界

- 当前正式本机/LAN 入口仍为 `http://127.0.0.1:27019/?map=de_dust2` 和 `http://192.168.1.100:27019/?map=de_dust2`；本轮没有自动切换生产服务。
- 候选发布工具只负责构建、哈希、preflight 和生成回退计划，不自动停止或替换活动实例。
- 同机双 SDK 只证明消息链和权威房间行为，不等同于两台物理电脑、真实浏览器、GPU 性能或长时间稳定性。
