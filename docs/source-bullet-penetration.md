# Source 子弹穿透边界

Source 地图射线现在支持基础多墙穿透：首个世界碰撞作为入射面，使用 Rapier 非实体射线并限定到**入射 collider 自身**求出口面，再沿射线最多处理四个有来源记录的连续实体。每一层都按实际几何厚度累计衰减；演员只有落在当前出口与下一层入射面之间的自由段才进入 authority 命中路径，第二层之后的演员不会被单层近似误命中。没有可验证出口、来源记录或超过四层预算时，子弹停在最近墙体。

当前碰撞导出没有携带原始 `surface penetration modifier`，因此步枪和手枪仍使用武器穿透上限与几何厚度的保守模型（AK-47 0.60m、M4A4 0.50m、沙鹰 0.40m、Glock/USP 0.25m）。本地 `research/source-items-catalog.json` 的 `weapon_awp_prefab` 记录 `penetration=2.5`；AWP 的 0.75m 几何上限是 AK-47 上限的 1.25 倍推导值，明确属于适配器推断，不是原生材质算法回读。倍率按每层线性累计并保持不增加原始伤害；超过单层上限为 0，四层后停止。友伤倍率仍在统一的 `damage()` authority 末端应用，不会绕过 `mp_friendlyfire` 规则。

这实现了可验证的多层“可穿透墙体并衰减”运行规则，仍不宣称与原版材质穿透修正、破坏性材质、动态实体过滤或完整实体伤害副作用完全一比一。补齐 BSP 表面属性后，应把材质系数接入同一逐层出口测厚接口，并重新以原生射线样本验收。
