# 改键与输入映射

设置面板提供一组基础动作的改键：移动（前后左右）、跳跃、交互、购买和死亡观战切换。点击输入框后按下目标按键即可，保存设置后当前局立即使用新映射。

映射使用浏览器 `KeyboardEvent.code` 保存，而不是受键盘布局影响的字符值。默认值为 `W/A/S/D`、`Space`、`E`、`B` 和 `Space`（观战切换）。显示层将 `KeyW`、`Digit2` 等代码转换为简短标签，重新载入页面时从 `localStorage` 的 `breachline.settings` 读取。

持久化数据会经过白名单规范化；未知或损坏的值自动回退到对应默认键。运行时移动、跳跃、交互、购买和观战事件都读取同一份配置，因此设置面板与实际输入保持一致。蹲下、行走、换弹和投掷物快捷键仍使用原有固定快捷键。

改键只影响本地输入层，不改变联机协议或服务器的权威判定。
