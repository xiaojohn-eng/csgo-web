# Source 死亡观战（R4）

当前 R4 在本地行动员死亡后进入基础队友观战：客户端从权威快照中选择同阵营、仍存活的队友，将镜头和音频监听点跟随到该队友的插值状态。敌方、已死亡队友和本地死亡体不会成为观战目标。

按空格可在存活队友之间循环切换；目标死亡或离开插值快照时会自动选择下一个合法目标。重新部署、半场换边、离开房间或页面重置都会清除客户端目标。观战选择只影响镜头与 HUD 提示，死亡席位的输入仍由服务器忽略，不改变伤害、可见性或比赛状态。

## 验收

- `tests/spectator.test.ts`：3 个测试、7 个断言覆盖死亡门槛、阵营隔离、目标失效和循环顺序。
- 浏览器需要在完整短竞技中实测：死亡后镜头跟随队友、空格切换、目标死亡后的回退、回合结算和下一回合恢复；本次代码提交没有把单机单端读回当作两台物理设备验收。

## 当前边界

这是基础第一人称队友观战，不声称已经复刻原版所有观察者模式（自由视角、第三人称、死亡回放、裁判视角、敌方观看权限或完整观战 HUD）。这些扩展仍须按原始协议和真实浏览器验收逐项补齐。
